# 東京・神奈川 3D 地理マップ

東京・神奈川の路線と街をゆるっと眺める 3D 地理マップ（HTML1枚・自己完結）。

公開URL: https://fujimoto-cpu.github.io/tokyo-map/

## 機能
- 🚃 主要路線（山手/中央総武/京浜東北/東横/丸ノ内/京急/小田急/田園都市）＋お気に入りピン
- 📍 現在地表示（GPS・青ドット／HTTPS必須）
- 👀 見る / 💡 豆知識 / 🎯 クイズ の3モード
- ＋−・ピンチで拡大（街レベルまで）、🔄で3D回転、↺で視点リセット
- iPhone「ホーム画面に追加」でアプリのように起動（PWAメタ対応）

## 更新のしかた
`index.html` を直して push すれば GitHub Pages に自動反映。
旧版は `bk/` に退避（versioning ルール準拠）。
